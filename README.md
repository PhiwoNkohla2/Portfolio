# 🌐 Personal Portfolio Website

Welcome to my personal portfolio website! This project showcases my skills, projects, and growth as a developer. It serves as a central place where I highlight my technical abilities, creative work, and experience in building modern, responsive, and user-friendly websites.

## 👩‍💻 About Me

Hi, I'm **Phiwokuhle Lihle Nkohla**, an aspiring software developer passionate about creating meaningful digital experiences through technology.

I enjoy learning new technologies, solving problems through code, and developing applications that are efficient, accessible, and visually appealing.

This portfolio was created to showcase my journey, skills, and projects as I continue to grow in the field of software development.

- Personal introduction and profile section
- Skills showcase
- Projects portfolio
- Contact information
- Clean and user-friendly interface
